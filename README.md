# Rodokmen

Evaluace Claude pro skládání rodokmenu z českých matrik a stavbu rodinného webu.

- Práci vede skill rodokmen, přibalený v `.claude/skills/rodokmen/`.
- Rodokmeny jsou ve složce `projekty/<název>/`.
- Pokyny pro Claude jsou v [CLAUDE.md](CLAUDE.md).

Začátek: v session Claude Code napište „chci začít rodokmen“.

## Původ skillu

Skill **rodokmen** není náš – jeho autorem je **Jindřich Šaršon**, zdroj je
[github.com/sarsonj/rodokmen-skill](https://github.com/sarsonj/rodokmen-skill) (licence MIT, viz
`.claude/skills/rodokmen/LICENSE`). Tady je jen nezměněná kopie, protože v cloudových session nejde
instalovat pluginy. Verze kopie je v `.claude/skills/rodokmen/VERZE`.
