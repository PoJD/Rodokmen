# Rodokmen

Evaluace Claude pro skládání rodokmenu z českých matrik a stavbu rodinného webu.

- Práci vede skill [rodokmen](https://github.com/sarsonj/rodokmen-skill), přibalený v `.claude/skills/rodokmen/`.
- Rodokmeny jsou ve složce `projekty/<název>/`.
- Pokyny pro Claude jsou v [CLAUDE.md](CLAUDE.md).

Začátek: v session Claude Code napište „chci začít rodokmen“.
